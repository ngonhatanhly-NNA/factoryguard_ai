# FactoryGuard AI Project Plan

## Phase 1 — Baseline
- Dataset inspection and EDA
- Train/dev/test split
- Random baseline
- Logistic Regression baseline
- Initial error analysis

## Phase 2 — Classical ML and Neural Networks
- Feature engineering (e.g., HOG)
- Decision Trees, Random Forest
- Small fully connected neural network

## Phase 3 — CNN
- CNN architecture, augmentation, tuning

## Phase 4 — Transfer Learning
- Frozen backbone, fine-tuning, comparison

## Phase 5 — Anomaly Detection
- One-class models, autoencoders, thresholding

## Phase 6 — Sensor and Sequence Modeling
- Time-series preprocessing
- RNN/LSTM/GRU for failure risk

## Phase 7 — Recommendation and Decision Making
- Risk-aware maintenance recommendations

## Phase 8 — Reinforcement Learning
- Environment/state/action/reward
- Q-learning and Deep Q-learning for scheduling

## Phase 9 — Integrated System
- End-to-end industrial AI pipeline
